# Security Policy

## Supported Versions

Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's
["Report a vulnerability"](https://github.com/OverskillDev/openui-rails/security/advisories/new)
feature (Security tab → Report a vulnerability) rather than opening a public
issue.

If that isn't available, email the maintainer listed in the gemspec. Include:

- A description of the vulnerability and its impact.
- Steps to reproduce (a minimal OpenUI Lang program or library definition
  that triggers it, where applicable).
- The gem version and Rails/Ruby versions involved.

We'll acknowledge reports within a few days and aim to ship a fix or
mitigation before any public disclosure.
